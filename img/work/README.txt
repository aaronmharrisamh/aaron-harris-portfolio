Real portfolio images live here.

Workflow: copy your final images into this folder, open the live page, run
edit() in the F12 console, and drag & drop the same files onto a carousel
(or an open deep-dive drawer). The editor writes img/work/<filename> paths
into the exported index.html. Filenames must match exactly.

Keep files web-ready: JPG, ~1600px on the long edge, a few hundred KB max.
