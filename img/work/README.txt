Real portfolio images live here.

Carousels (the home page projects and their deep dives): open the served
page, turn on the editor (the EDIT corner, or edit() in the F12 console),
and press (+) on a carousel, or drop a photo onto it. The Add a photo box
takes a JPG, PNG or WebP from anywhere on your machine and makes a
web-ready copy: a JPG, 1600px on the long edge. Save to repo writes that
copy into this folder, beside the page that shows it. Then commit and push.

A name already in use is never overwritten. A second "hangar.png" is
saved as hangar-2.jpg.

Gallery page tiles still work the older way: copy your final images into
this folder first, then drop the same files onto a tile. The editor writes
img/work/<filename> paths into the page, so filenames must match exactly.

Keep files web-ready: JPG, ~1600px on the long edge, a few hundred KB max.
