The Markdown fixture. Each case is: a name line, the source, a line of
four dashes, the expected HTML from AMH.markdown.render(source). Cases are
separated by a line of four equals signs. The renderer is done when every
case renders byte for byte. A feature outside this file is text.
====
headings: one to three levels, a fourth is text, inline marks apply
# One
## Two **bold**
### Three
#### Four
----
<h2>One</h2>
<h3>Two <strong>bold</strong></h3>
<h4>Three</h4>
<p>#### Four</p>
